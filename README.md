# Shop Backend API 

A robust RESTful API for an E-commerce system built with Java and Spring Boot.

##  Technologies Used
*   **Java 17**
*   **Spring Boot 3** (Web, Data JPA, Security)
*   **Database:** MySQL
*   **Security:** JWT Authentication & Authorization
*   **Testing:** JUnit 5 & Mockito
*   **Documentation:** Swagger UI / OpenAPI

##  Key Features
*   **User Authentication:** Secure Login/Register using JWT.
*   **Product Management:** CRUD operations for products.
*   **Security:** Role-based access control (Admin/User).
*   **Error Handling:** Global exception handling with meaningful JSON responses.
*   **API Documentation:** Interactive API testing via Swagger.
